# Формат данных

Основной датасет проекта — SMS Spam Collection, `data/raw/spam.csv`: `v1` содержит метку (`ham` или `spam`), `v2` — текст сообщения. Возможны завершающие пустые CSV-колонки — загрузчик игнорирует их. Также поддерживается стандартный формат CSV `text,label`. Кодировка UTF-8. `text` — непустой текст, `label` — `spam`/`not_spam` (допускается `ham`) либо `1`/`0`. Не добавляйте приватную переписку в Git.

Команда `make prepare-data` создаёт стратифицированные train/validation/test CSV в `data/processed/` с теми же колонками и каноническими метками `spam` и `not_spam`.
